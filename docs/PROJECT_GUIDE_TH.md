# ระบบแนะนำอาหารจากความชอบและการเลือก

รัน pip install -r requirements.txt แล้ว streamlit run app.py
คัดลอก .streamlit/secrets.toml.example เป็น secrets.toml และกรอกข้อมูล Neo4j ของคุณ

## หน้า "แนะนำอาหาร"
เลือกผู้ใช้เพื่อดูคำแนะนำอาหารที่เหมาะสม ระบบหาแนะนำจากอาหารที่เพื่อนของคุณเลือก

## หน้า "จัดการอาหาร"
เพิ่ม/ลบอาหาร บันทึกการเลือกของผู้ใช้ และอัปโหลด/แก้ไขรูปอาหาร ระบบมีข้อมูลตัวอย่าง 10 อาหารและ 21 ความสัมพันธ์การเลือก

## หน้า "จัดการคน"
เพิ่ม/ลบผู้ใช้ และเพิ่ม/ลบความสัมพันธ์เพื่อน

## หน้า "กราฟความสัมพันธ์"
แสดง Neo4j graph ของผู้ใช้ ความเป็นเพื่อน และอาหารที่เลือก

## คะแนนแนะนำ
คะแนน = จำนวนเส้นทางความคล้ายที่ไม่ซ้ำ เส้นทางคือ ผู้ใช้ → อาหารที่เลือก → เพื่อน → อาหารใหม่ ตัดอาหารที่ผู้ใช้เลือกแล้ว เลือกเดิมซ้ำไม่เพิ่มเส้นทางซ้ำ ระบบอธิบายเพื่อนที่เลือกอาหารนั้นและแสดงรูปอาหาร
